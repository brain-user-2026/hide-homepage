# Open Newstages AI

Netlifyで公開している静的ホームページです。

## 公開URL

https://open-newstages-ai.com

## 構成

- `index.html`：トップページ
- `about.html`：会社概要
- `service.html`：サービス
- `company.html`：会社情報
- `contact.html`：お問い合わせ
- `assets/`：画像・CSS・JavaScript

## デプロイ

GitHubの `main` ブランチに変更を反映すると、Netlifyへ自動デプロイされます。

## 編集ルール

- 既存デザインを大きく壊さない
- 日本語サイトとして自然な文章にする
- Google Workspace / Netlify / GitHub の設定は勝手に変更しない
- 変更前に目的を明確にする
