# Assyu Sound Lab

Assyuの商用BGM・SNSサウンドを紹介する公開トップページです。

## 公開ページ

- `index.html`: Assyu LP
- `assets/assyu/`: LP専用スタイルシートとビジュアル素材

## 継続利用する家計簿アプリ

- `Input.html`: 家計簿アプリの画面
- `household-accounting-app.gs`: 家計簿アプリのGoogle Apps Script

GitHubの`main`ブランチへの反映後、Netlifyで公開されます。

## お問い合わせ（Netlify Forms）

`index.html`末尾のフォーム（`name="contact"`）を静的HTMLとして定義しています。`data-netlify="true"`と`form-name`で検出・識別し、`bot-field`をハニーポットとして送信します。独自API・APIキー・追加依存関係は不要です。

- `assets/assyu/contact.js`: 同一オリジンの`/`へURLエンコードしたPOSTを送信。送信中は入力・重複送信を抑止し、成功時は入力を消去、HTTPエラー・通信失敗・20秒のタイムアウト時は入力を保持して結果を表示します。タイムアウトは受付済みの場合もあるため、失敗時の自動再送は行いません。
- JavaScriptが無効な場合も通常のPOSTで送信し、Netlify標準の結果画面を使用します。
- 必須項目・メール形式・文字数上限はブラウザ側の入力支援であり、直接POSTによる回避は防ぎません。受信内容は常に未信頼のテキストとして扱ってください。
- 入力内容は画面へHTMLとして挿入せず、URL・ブラウザストレージ・コンソールへ保存しません。既存のCSP・セキュリティヘッダーは維持しています。
- `/assets/*`は長期間キャッシュされます。公開後にフォームのJS/CSSを更新する際は、HTML側のアセットURLにバージョンを付けるなどしてキャッシュを更新してください。

### 公開時の確認（この実装作業では公開しません）

1. Netlify管理画面のFormsでフォーム検出が有効であることを確認し、次回の承認済み公開後に`contact`が検出され、ハニーポットが有効になっていることを確認します。
2. FormsのSubmission notificationsで通知先メールアドレスを設定・確認します。お名前・メール・本文を含むテストをPCとスマートフォンから送り、管理画面への保存、通知メールの受信、`email`によるReply-toと返信先への到達を確認します。送信者への自動返信メールは実装していません。
3. 日本語・改行・`&`などが正しく届くこと、必須・メール形式・文字数制限、連打時の抑止、通信遮断時のエラーと入力保持、JavaScript無効時の通常送信を確認します。
4. ハニーポットに値を入れたテストが受理されないことを確認し、通常のテストがSpamへ誤分類されていないかも確認します。ハニーポットで拒否された送信はSpam一覧にも残らない場合があります。
5. 受信情報はNetlify上に保存されます。管理者権限・通知先・保存期間・削除運用と、利用プランの制限を公開前に確認してください。ハニーポットは全てのスパムを防ぐものではありません。

ローカルの静的サーバーではNetlifyによる受付・スパム判定・メール通知は検証できません。これらは公開後の確認が必要です。戻す場合はフォーム追加部分と専用JS/CSSおよび本READMEの関連説明を戻します。`netlify.toml`の変更は不要です。

公式資料: [フォーム設定](https://docs.netlify.com/manage/forms/setup/)、[スパム対策](https://docs.netlify.com/manage/forms/spam-filters/)、[通知設定](https://docs.netlify.com/manage/forms/notifications/)
